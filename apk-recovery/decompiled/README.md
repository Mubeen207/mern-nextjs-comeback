# Decompiled Sources

This directory is an evidence archive extracted from the APK, not a Gradle source set.

The `sources/` tree includes Android framework, AndroidX, Google Play Services, Kotlin, and Flutter classes. JADX could not reconstruct every method, so some files contain `Method not decompiled` or intentional `UnsupportedOperationException` stubs. Those entries are expected decompiler limitations and are not errors in the reconstructed application.

Build the maintained project from `reconstructed/snake-engine/`. VS Code is configured to keep this evidence archive out of Java project source paths.
